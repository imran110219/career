# Job Preferences

## Career Priorities

1. International relocation with employer-sponsored visa or clear relocation support.
2. Remote work that explicitly permits working from Bangladesh.

## Target Markets

Priority order:

1. Saudi Arabia
2. United Arab Emirates
3. Malaysia
4. Turkey
5. Indonesia

Secondary consideration may be given to other MENA or APAC locations when sponsorship, relocation, or Bangladesh-eligible remote work is explicit.

## Target Roles

- Senior Backend Engineer
- Senior Java Engineer
- Technical Lead / Backend Lead
- Staff Software Engineer
- Software Architect
- Solution Architect

Prefer hands-on individual-contributor or technical-lead roles. Engineering Manager roles are secondary unless they include substantial technical delivery and the posting does not require unsupported formal people-management scope.

## Technical Fit Priorities

Highest-weight terms:

- Java and Spring Boot
- REST APIs and microservices
- PostgreSQL, Redis, database design, and query optimization
- Distributed systems and API architecture
- Security, authorization, and data integrity
- Technical leadership, code review, mentoring, and stakeholder collaboration

Positive but verify by job and evidence:

- Kubernetes, Docker, CI/CD, RabbitMQ, GitHub Actions, Jenkins, Nginx, Locust, Keycloak, OpenAPI, observability, and cloud platforms

## Compensation and Work Authorization

- Rank posted salary and benefits when available, but never invent or estimate a salary range as fact.
- Record salary currency, period, and whether the range is base, total, or estimated.
- Prefer roles explicitly offering visa sponsorship, work authorization, relocation, or Bangladesh-eligible remote work.
- Treat unspecified sponsorship as requiring verification, not as confirmed eligibility.
- Exclude roles requiring citizenship, permanent local work rights, or local residency unless the candidate confirms eligibility.

## Exclusions

- Fintech, cryptocurrency, gambling, and iGaming roles unless the candidate explicitly changes this preference.
- Management-only roles.
- Frontend-only, mobile-only, QA-only, support-only, junior, graduate, and internship roles.
- Roles whose primary requirements are unsupported advanced Kubernetes administration, deep Terraform ownership, production SRE ownership, cloud-platform ownership, or advanced observability engineering.
